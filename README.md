# ProyectoIntermodular-SMR-25-26-26-27-

Digitalización e introducción de nuevas tecnologías en una PYME

Este repositorio contiene la documentación y desarrollo de mi proyecto final para el ciclo de Sistemas Microinformáticos y Redes (SMR). El caso práctico se centra en la modernización tecnológica de una tienda tradicional (venta de embutidos) mediante la implantación de una red centralizada y segura.

🚀 Resumen del Proyecto

El objetivo principal es abandonar la gestión tradicional para pasar a un modelo digital eficiente. Para ello se ha diseñado una infraestructura que cuenta con un servidor central y varios equipos cliente con distintos sistemas operativos, garantizando la seguridad, interoperabilidad y el control del negocio.

🎯 Puntos Clave

Diseño de un escenario de red virtualizado.

Implantación de un servidor centralizado para la gestión corporativa.

Integración de sistemas operativos heterogéneos (Windows y Linux) en los puestos de trabajo.

🛠️ Stack Tecnológico

Virtualización: Oracle VirtualBox

Servidor: Windows Server 2022

Clientes: Windows 10 y Ubuntu 24.04 Desktop

Ofimática: Microsoft Office
